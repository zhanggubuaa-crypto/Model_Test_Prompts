# 時計 & カウントダウン（3-in-1ツール）

## 概要
3つの時間関連ツールをタブ切替で1画面に統合した実用ツールを作成してください。デジタル時計、ストップウォッチ、カウントダウンタイマーの3機能を含みます。

## 必須機能

### タブ1: デジタル時計
- 現在時刻を `HH:MM:SS` 形式で大きく表示
- 今日の日付と曜日を表示（例: 2026年5月9日 (土)）
- 12時間 / 24時間 表示の切替

### タブ2: ストップウォッチ
- スタート / 一時停止 / リセット ボタン
- 経過時間を `HH:MM:SS.cs`（センチ秒まで）で表示
- ラップ機能: 「ラップ」ボタンで途中時間を記録、ラップ一覧をリスト表示
- ラップ間の差分も表示（例: +00:12.34）

### タブ3: カウントダウンタイマー
- 時・分・秒を入力するフィールド
- スタート / 一時停止 / リセット ボタン
- 残り時間を大きく表示
- 設定した時間とスタート/一時停止状態を `localStorage` に保存（リロードしても継続）
- 0秒到達時にアラート音またはビジュアル通知（点滅等）

## UI/UX要件
- 3タブを上部に配置し、選択中タブをハイライト
- 各機能とも中央寄せの大型表示で視認性を確保
- ボタンは状態に応じて適切に切替（例: スタート中は「一時停止」表示）
- ダーク基調のシンプルなデザイン

## 技術要件
- 単一の `index.html` にすべて埋め込む
- 外部ライブラリ不使用
- アラート音は Web Audio API で生成、または `<audio>` 要素＋短いビープを使用
- タイマーは `setInterval` の誤差を考慮し、必要なら `Date.now()` ベースで補正

## 評価ポイント
- 3機能ともタブ切替で状態が壊れず保持されるか
- ストップウォッチの精度（長時間でずれないか）
- カウントダウンの永続化が正しく機能するか
- 視覚的な見やすさ・操作性
