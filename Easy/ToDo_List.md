# ToDoリスト（永続化対応タスクマネージャー）

## 概要
ブラウザを閉じてもデータが消えない、永続性のあるタスクマネージャーをゼロから構築してください。シンプルですが実用に耐える品質を目指します。

## 必須機能
- タスクの追加（テキスト入力 + Enterキー または「追加」ボタン）
- タスクの完了切替（チェックボックスまたはクリック）
- タスクの削除（×ボタン）
- タスクの編集（ダブルクリックまたは編集ボタンでインライン編集）
- フィルター切替: 「すべて / 未完了 / 完了」
- 「完了済みをすべて削除」ボタン
- 残タスク件数の表示（例: 「未完了: 3件」）
- localStorage によるデータ永続化（リロードしても復元される）

## UI/UX要件
- クリーンでミニマルなデザイン（カードまたはリスト形式）
- 完了済みタスクは取り消し線 + 薄い文字色で視覚的に区別
- 空のリストの場合は「タスクがありません」のような空状態メッセージを表示
- 入力欄は常に画面上部に固定し、すぐ追加できる導線
- ホバー時のフィードバック（削除ボタンが現れる等）

## 技術要件
- 単一の `index.html` にHTML/CSS/JSをまとめる
- 外部ライブラリ不使用
- データは `localStorage` に JSON で保存
- データ構造例: `[{ id: string, text: string, done: boolean, createdAt: number }]`

## 評価ポイント
- リロード後もデータが正しく復元されるか
- 編集・削除・フィルターが直感的に動作するか
- 空状態・大量データ（50件以上）でも崩れないか
- IDの一意性が担保されているか
