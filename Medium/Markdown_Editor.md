# Markdownエディター（リアルタイムプレビュー & 自動保存）

## 概要
左右分割のリアルタイムプレビューと自動保存機能を備えた、執筆に集中できるMarkdownエディターを作成してください。物書きが気持ちよく使える品質を目指します。

## 必須機能

### コア機能
- 左ペイン: Markdownエディタ（テキストエリア）
- 右ペイン: HTMLレンダリング結果（リアルタイム反映）
- 中央のドラッグ可能なディバイダで左右の幅を調整可能
- 入力後 500ms程度のデバウンスで自動的に `localStorage` に保存
- 「最終保存: ◯秒前」のステータス表示

### Markdown対応
- 見出し (H1〜H6)
- 太字・斜体・取り消し線
- リスト（順序あり/なし）、ネスト対応
- リンク・画像
- インラインコード・コードブロック（シンタックスハイライト推奨）
- 引用・水平線
- 表（テーブル）
- チェックボックスリスト

### ツールバー
- 太字 / 斜体 / 見出し / リンク / コード / 引用 などのワンクリック挿入ボタン
- 「ダウンロード (.md)」ボタン
- 「HTMLとしてエクスポート」ボタン
- 「クリア」ボタン（確認ダイアログ付き）

### 補助機能
- 文字数・単語数・読了時間の表示
- ダーク / ライト テーマ切替
- フォーカスモード（ツールバーを隠して執筆に集中）

## UI/UX要件
- 上部にツールバー、下部にステータスバー、中央に左右分割エディタ
- プレビュー側は読み物として美しい組版（適切な行間、最大幅、余白）
- スクロール同期（オプション、左右どちらかに連動）
- ショートカット: `Ctrl+B` 太字、`Ctrl+I` 斜体、`Ctrl+S` 即時保存

## 技術要件
- 単一 `index.html`
- Markdownパーサーは CDN経由で `marked` または `markdown-it` を利用可
- シンタックスハイライトは CDN経由の `highlight.js` 等を利用可
- それ以外のフレームワーク（React/Vue等）は不使用

## 評価ポイント
- 入力からプレビュー反映までのラグ（重くないか）
- 自動保存・復元が確実に動くか
- 表・コードブロック・画像が崩れず描画されるか
- ディバイダのドラッグ操作が安定しているか
- 長文（5000文字以上）でも快適か
