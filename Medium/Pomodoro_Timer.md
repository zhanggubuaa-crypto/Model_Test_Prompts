# ポモドーロタイマー（カスタマイズ・テーマ・分析機能付き）

## 概要
カスタマイズ可能な作業フェーズ、複数テーマ、Chart.js による分析機能を備えた、本格的な集中作業用ポモドーロタイマーを作成してください。

## 必須機能

### タイマーコア
- 3つのフェーズ: 「作業」「短い休憩」「長い休憩」
- 各フェーズの分数をカスタマイズ可能（デフォルト: 25 / 5 / 15 分）
- 「N回ごとに長い休憩」の設定（デフォルト: 4回）
- スタート / 一時停止 / スキップ / リセット ボタン
- 大きな時刻表示と、円形プログレスバー（残り時間を視覚化）
- フェーズ切替時に通知音 + ブラウザ通知（許可があれば）

### セッション管理
- 完了した作業セッション数を表示
- 本日 / 今週 / 全期間の累計を表示
- セッション履歴を `localStorage` に保存（日時、フェーズ種別、設定時間）

### テーマ
- ライト / ダーク / 高コントラスト など、最低3種類のテーマを切替可能
- テーマ選択は `localStorage` に保存

### 分析機能（Chart.js 使用）
- 過去7日間の作業セッション数（棒グラフ）
- 時間帯別の集中時間分布（折れ線または棒）
- フェーズ別の総時間内訳（円グラフまたはドーナツ）
- 期間切替: 「7日 / 30日 / 全期間」

### 設定パネル
- 各フェーズ時間のカスタマイズ
- 通知音のON/OFFと種類選択（最低2種類）
- 自動で次フェーズを開始するかどうかのトグル
- 設定は `localStorage` に保存

## UI/UX要件
- メイン画面はタイマーに集中できるシンプルなレイアウト
- 「タイマー / 分析 / 設定」のタブまたはサイドナビ
- 現在のフェーズが一目で分かる色分け（作業=赤系、短休憩=緑、長休憩=青 など）
- タイマー稼働中はタブのタイトルにも残り時間を表示
- レスポンシブ対応

## 技術要件
- 単一 `index.html`
- CDN経由で `Chart.js` を利用
- 通知は Web Notifications API
- 通知音は Web Audio API または `<audio>` 要素

## 評価ポイント
- タイマー精度（バックグラウンドタブでもズレない工夫）
- 設定変更が即座に反映されるか
- 分析グラフが空データでも壊れないか
- テーマ切替が全画面に正しく適用されるか
- 履歴データの構造設計
