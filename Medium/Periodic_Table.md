# インタラクティブ周期表（教育用）

## 概要
カテゴリによる絞り込みと詳細な元素情報を備えた、教育用の周期表を作成してください。化学を学ぶ学生が触って楽しく、情報密度の高い学習教材を目指します。

## 必須機能

### 周期表表示
- 118元素すべてを正しい配置で表示（ランタノイド・アクチノイドは下段に独立表示）
- 各セルに表示する情報:
  - 原子番号
  - 元素記号（大きく）
  - 元素名（日本語）
  - 原子量
- カテゴリ別の色分け:
  - アルカリ金属 / アルカリ土類金属 / 遷移金属 / 後遷移金属 / 半金属 / 非金属 / ハロゲン / 希ガス / ランタノイド / アクチノイド

### 絞り込み・ハイライト機能
- カテゴリチェックボックスで該当元素のみハイライト（他は薄く）
- 状態（固体・液体・気体・人工）でのフィルタ
- 検索ボックス（元素名・記号・原子番号で検索）
- 周期・族のラベルにマウスオーバーすると行/列をハイライト

### 詳細パネル
- 元素クリックでサイドパネルまたはモーダルに詳細表示:
  - 元素記号・名前・原子番号・原子量
  - 電子配置
  - 電気陰性度
  - 融点・沸点
  - 密度
  - 発見年・発見者
  - カテゴリ
  - 簡単な説明文（用途・特徴など、1〜3行）
  - 常温での状態

## UI/UX要件
- 本物の周期表のレイアウトを忠実に再現（空白セルも正しく配置）
- カテゴリ凡例を画面下部または横に配置
- セルはホバーで拡大・浮き上がり等のフィードバック
- レスポンシブ対応（PC優先、タブレットでも崩れない）
- ダーク基調 or 学習用に明るい背景、選択可能だとなお良い

## 技術要件
- 単一 `index.html`
- 元素データはJS内に配列として埋め込む（外部API不要）
- グリッドレイアウトは CSS Grid を活用
- 外部フレームワーク不使用

## 評価ポイント
- 118元素すべての配置が正しいか（特にランタノイド・アクチノイドの位置）
- データの正確性（原子量・電子配置等）
- 絞り込み・検索の応答速度
- 詳細パネルが見やすく整理されているか
- 周期・族のラベル表示
