# カンバンボード（ドラッグ＆ドロップ・絞り込み・永続化）

## 概要
ブラウザ標準のドラッグ＆ドロップ、絞り込み機能、データ保存機能を備えた、フル機能のカンバンボードを作成してください。Trello風のタスク管理アプリとして実用に耐える品質を目指します。

## 必須機能

### ボード構造
- 複数カラム（デフォルト: 「ToDo」「進行中」「レビュー」「完了」）
- カラムの追加・削除・名前変更・並び替え
- 各カラムにカード数のバッジを表示
- WIP制限（カラムごとの上限件数、超えると警告色）

### カード機能
- カード追加（タイトル必須、詳細はモーダルで編集）
- カード詳細フィールド:
  - タイトル
  - 説明（複数行、Markdown対応だとなお良い）
  - 期日
  - 優先度（低 / 中 / 高 / 緊急、色で区別）
  - タグ（複数、カラフルなチップ表示）
  - 担当者（任意）
  - チェックリスト（サブタスク）
  - コメント履歴
- カードの編集・複製・削除
- カードのアーカイブ機能

### ドラッグ＆ドロップ
- HTML5 標準の Drag and Drop API を使用（外部ライブラリ不可）
- カードを別カラムへ移動可能
- カード同士の並び替え（同一カラム内・カラムをまたいで）
- カラム自体の並び替えもドラッグで可能
- ドラッグ中のビジュアルフィードバック（ゴースト・挿入位置のハイライト）

### 絞り込み・検索
- テキスト検索（タイトル・説明・タグ・コメントを横断）
- タグによる絞り込み（複数選択可）
- 優先度・担当者による絞り込み
- 期日（今日 / 今週 / 期限切れ）でのクイックフィルタ
- フィルタ適用中は該当しないカードを非表示または淡色化

### データ管理
- すべての変更を `localStorage` に自動保存
- ボードのJSONエクスポート / インポート機能
- 複数ボード対応（ボード切替メニュー）
- アンドゥ機能（最低でも直前1操作）

## UI/UX要件
- 横スクロール対応のカラムレイアウト
- カードはコンパクトに、必要な情報が一目で見える
- ダーク / ライト テーマ切替
- キーボードショートカット:
  - `N` 新規カード
  - `/` 検索フォーカス
  - `Esc` モーダル閉じる
- アニメーション（カード追加・削除・移動時）
- レスポンシブ（PC優先、タブレットでも操作可能）

## 技術要件
- 単一 `index.html`（または分割しても可。その場合は構成を明記）
- 純粋なJS（フレームワーク不使用）
- DnDは HTML5 Drag and Drop API を使用（SortableJS等の補助ライブラリは不可）
- データ構造例:
  ```
  {
    boards: [{ id, name, columns: [{ id, name, wipLimit, cards: [{ id, title, description, dueDate, priority, tags, assignee, checklist, comments, archived }] }] }],
    activeBoard: id
  }
  ```

## 評価ポイント
- DnDが滑らかで誤操作が少ないか（特にカラムをまたいだ並び替え）
- 大量カード（カラムあたり50件以上）でも快適か
- フィルタとDnDの組み合わせで挙動がおかしくならないか
- データ構造の設計と永続化の堅牢性
- UIの完成度・操作性
- エクスポート / インポートで完全に状態を復元できるか
