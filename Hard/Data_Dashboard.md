# 株式市場データダッシュボード（リアルタイム）

## 概要
API連携、インタラクティブなチャート、ウォッチリスト機能を備えた、リアルタイムな株式市場ダッシュボードを作成してください。本格的な投資ツールに近い使用感を目指します。

## 必須機能

### データ取得
- 無料の株式・金融データAPIから取得（例: Alpha Vantage、Finnhub、Yahoo Finance非公式、Twelve Data など）
- APIキーは `index.html` 内の設定画面から入力・`localStorage` 保存
- レート制限を考慮し、適切にキャッシュ・リトライ

### メインダッシュボード
- マーケット指標カード（S&P 500、NASDAQ、Dow など主要指数）
  - 現在値、前日比、変化率（プラス緑/マイナス赤）
- 自動更新（30秒〜1分間隔、間隔は設定可能）
- 最終更新時刻の表示

### 銘柄詳細ビュー
- ティッカー検索（オートコンプリート対応が望ましい）
- 選択銘柄の情報:
  - 現在値・前日比・始値・高値・安値・出来高
  - 時価総額・PER・配当利回り（取得可能なら）
- インタラクティブな価格チャート（Chart.js または同等のライブラリ）:
  - 期間切替: 1日 / 5日 / 1ヶ月 / 6ヶ月 / 1年 / 5年
  - ローソク足 または 折れ線
  - ホバーで日付・価格をツールチップ表示

### ウォッチリスト
- 銘柄を追加・削除
- ウォッチリスト内の各銘柄を一覧表示（現在値・変化率）
- クリックで詳細ビューに切替
- `localStorage` に永続化
- 並び替え（変化率・アルファベット順）

### エラーハンドリング
- APIエラー、ネットワークエラー、レート制限到達時の明示的な表示
- APIキー未設定時の案内画面

## UI/UX要件
- ダーク基調の金融系UI（Bloomberg風 or Robinhood風）
- 上部にマーケット指標、左にウォッチリスト、中央メインに詳細ビュー
- レスポンシブ対応（最低でも1280px幅で快適）
- ロード中スピナー、空状態の案内
- 色のアクセシビリティ（赤緑色覚異常を考慮、上下矢印など色以外の手がかりも併用）

## 技術要件
- 単一 `index.html`
- CDN経由で `Chart.js` 等のチャートライブラリを利用可
- フェッチは `fetch()` API、Promise/async-await で記述
- フレームワーク不使用（純粋なJS）
- APIキーや個人情報は `localStorage` のみ、外部送信しない

## 評価ポイント
- API連携が実際に動作するか（READMEまたは画面内に使用APIの選択肢と取得方法を案内）
- レート制限やエラー時の堅牢性
- チャートの操作性とパフォーマンス
- ウォッチリストの永続化と並び替え
- UIの完成度（プロダクトとして見られる水準か）
- コード分割（API層・UI層の分離）
